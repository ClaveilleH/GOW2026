# GOW2026 - Projet Babylon.js

## Description
Projet de programmation 3D utilisant Babylon.js

## Structure du projet
```
├── index.html          # Point d'entrée HTML
├── src/
│   ├── main.js        # Code JavaScript principal
│   └── style.css      # Styles CSS
├── assets/
│   ├── models/        # Modèles 3D
│   └── textures/      # Textures
└── package.json       # Configuration npm
```

## Installation

1. Installer les dépendances :
```bash
npm install
```

## Démarrage

Pour lancer le serveur de développement :
```bash
npm start
```

Ou avec un port spécifique :
```bash
npm run dev
```

Puis ouvrir votre navigateur à l'adresse : `http://localhost:3000`

## Technologies utilisées
- Babylon.js - Moteur de rendu 3D
- WebGL
